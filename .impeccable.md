## Design Context

### Users
Frontend engineers and designers assembling product UIs and marketing surfaces. They want copy-paste components that feel finished without fighting a heavy design system.

### Brand Personality
Quiet · Precise · Refined

Emotional goals: calm confidence, clarity, restraint. Delight comes from spacing and motion, not decoration.

### Aesthetic Direction
**Utilitarian minimalism** — hairline borders, warm bone canvas, typographic contrast, almost no shadow.

**References (steal principles, not clones):**
- **shadcn/ui** — own-the-code components, accessible defaults, composition
- **Origin UI / coss ui** — dense app-primitive catalog, Base UI patterns
- **Magic UI** — selective Motion polish (marquees, reveals) without Aceternity spectacle
- **Codrops 3D infinite carousel** — fluid 3D card orbit as a signature piece

**Anti-references:** Material purple SaaS, neon glassmorphism, identical icon-card grids, cream+terracotta editorial cliché, broadsheet newspaper layouts, glow orbs.

**Theme:** Light-first with warm-stone dark mode (`.dark` on `<html>`). Soft ink on bone / stone. Pastel accents only on pills/status — retinted for dark.

### Design Principles
1. **Restraint first** — if removing a border, shadow, or radius does not hurt clarity, remove it.
2. **One accent language** — ink primary actions; pastels only for semantic chips.
3. **Motion is quiet** — transform + opacity only; respect `prefers-reduced-motion`.
4. **Own the source** — components live in-repo (shadcn model); no opaque runtime UI package.
5. **Signature pieces earn their weight** — unique components (3D carousel, marquee) must feel inevitable, not demoware.
